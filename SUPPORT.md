# Support

## Getting Help

- **Documentation**: `README.md`, `docs/language.md`, `examples/`
- **Discussions / Q&A**: https://github.com/MrModelOS/Glyph/discussions
- **Issues**: https://github.com/MrModelOS/Glyph/issues (bug reports, feature requests)

## Asking a good question

Include:

- `glyphc --version` and OS
- Minimal `.glyph` snippet and the exact command you ran
- Full error output (with `--emit-ir` if relevant)

## Commercial / sponsored support

Open a discussion or contact the maintainers via GitHub.
